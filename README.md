<!--
  Profile README for @JyotirmoyLaha

  Assets live in /assets and are hand-authored SVG. Two things matter when
  editing them:

  1. GitHub renders README images through its Camo proxy as <img>, which does
     NOT render <foreignObject> (HTML inside SVG). All text must be native
     <text>/<tspan>, and no content may depend on animation running.
  2. Every asset has a -light.svg twin, generated by tools/build-light.mjs.
     Edit the dark file, then re-run the generators:

         node tools/build-cards.mjs   # regenerates the project cards
         node tools/retheme.mjs       # palette + dead-CSS pass
         node tools/build-light.mjs   # regenerates every *-light.svg

  Bump the ?v= cache-bust param below after changing an asset, or GitHub's
  CDN will keep serving the old one.
